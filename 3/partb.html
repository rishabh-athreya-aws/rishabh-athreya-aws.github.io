Part 1 · Single-step denoising

1.1 Building the denoising U-Net

I implement the image-to-image model as a U-Net: convolutions learn local features, downsampling adds context, and upsampling restores the 28 × 28 resolution. Skip connections join encoder and decoder features at matching scales, preserving fine digit strokes that could be lost in the bottleneck. The provided blocks use convolution, batch normalization, and GELU; the output layer predicts one grayscale image.

1.2.2 Testing at unseen noise levels

The denoiser was trained with σ = 0.5. To check how it handles inputs outside that training condition, I hold one test digit and its noise pattern fixed, vary σ, and apply the same trained model to each version.

At lower noise levels, the digit stays legible with only a small perturbation. At high σ, the same 7 is harder to recover; the strongest-noise estimates become less faithful and develop extra marks. This illustrates the limit of a model trained on one noise strength when the input corruption changes.

Part 2 · Flow matching

2.1 Conditioning a U-Net on time

Flow matching trains a network to predict how an image should move from Gaussian noise toward a data example. A random MNIST image x₁ and noise x₀ define points along a straight interpolation; the target velocity is their constant difference. The model must see t because the same intermediate image statistics call for different predictions at different points along the path.

xt = (1 − t)x0 + tx1,   u = x1 − x0

A small fully connected block embeds the scalar time value. Its features modulate internal U-Net activations, while image skip connections continue to carry spatial detail. Training uses a mean-squared error between predicted and target velocity. At generation time, Euler steps repeatedly add the predicted velocity, updating the image and time together.

Part 2 · Flow matching

2.2 Training the time-conditioned flow model

The time-conditioned U-Net is trained on shuffled MNIST batches with random Gaussian starting points and random times. Each training example is interpolated between noise and a clean digit, and the model predicts x₁ − x₀. The run shown uses the assignment’s ten-epoch schedule, with an exponential learning-rate decay.

L = 𝔼x₀,x₁,t[‖uθ(xt, t) − (x₁ − x₀)‖²]

The loss falls sharply during the early updates, then changes more gradually as training continues. The curve tracks velocity-prediction error on training interpolants; sample grids are a separate visual check of whether integrating that field produces legible digits.

Part 2 · Flow matching

2.3 Sampling from the time-only model

Sampling starts from a fresh noise image at t = 0. I divide the interval into 50 Euler steps and repeatedly evaluate the time-conditioned network, moving each state toward t = 1. The grid shows ten independently seeded samples from each saved checkpoint.

xt+h = xt + h uθ(xt, t),   h = 1/50

Epoch 1 mostly produces fragmented strokes. By epochs 5 and 10, more samples have connected loops and recognizable digit-like structure, though several images remain malformed or ambiguous. Training improves the learned flow, but this unconditional model has no class label to control which digit should appear.

Part 2 · Flow matching

2.4 Class-conditioned U-Net

The class-conditioned U-Net receives both the current time and a one-hot digit label. Separate learned embeddings modulate decoder features so the model can steer its flow toward a requested class. During training, the label is dropped for 10% of examples; this teaches the same model to make unconditional predictions for classifier-free guidance.

vguided = vu + 5(vc − vu)

Part 2 · Flow matching

2.5 Training the class-conditioned models

Both models use the class-conditioned U-Net with hidden dimension 64 and 10% class dropout. The scheduled run uses Adam, starts at learning rate 0.01, and decays exponentially for ten epochs. The independent comparison uses a constant learning rate of 0.001, matching the scheduled run’s rate at the end of training.
